# alles-gesagt-scraper
Scrape all "ZEIT Alles gesagt?" podcast episodes. 

## Installation
Clone this repository and install it using pipx.
```
git clone https://github.com/adridevelopsthings/alles-gesagt-scraper
pipx install .
```

## Usage
Start it using
```
alles-gesagt-scraper
```
You can set a specific output path if you want (Default is `episodes`)
```
alles-gesagt-scraper -o /media/BlaBla/alles-gesagt
```
